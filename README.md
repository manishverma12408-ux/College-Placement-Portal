# 🎓 College Placement Portal

A **College Placement Portal** is a web-based platform designed to simplify and manage the college placement process for **students, placement officers, and recruiting companies**.

The portal provides a centralized system where students can view and apply for job opportunities, companies can manage recruitment activities, and placement officers can monitor and manage the complete placement process.

---

## 🚀 Features

### 👨‍🎓 Student

* Student registration and login
* Create and update profile
* Add academic details and skills
* Upload resume
* View available job opportunities
* Apply for eligible jobs
* Track application status
* View placement updates

### 🧑‍💼 Placement Officer

* Admin/placement officer login
* Manage student records
* Manage company information
* Add and manage job opportunities
* View student applications
* Monitor placement status
* Manage placement-related announcements

### 🏢 Company / Recruiter

* Company registration and login
* Create company profile
* Post job opportunities
* Set eligibility criteria
* View eligible student applications
* Shortlist candidates
* Manage recruitment process

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/manishverma12408-ux/College-Placement-Portal.git
```

### 2. Navigate to the Project

```bash
cd College-Placement-Portal
```

### 3. Install Dependencies

For the frontend:

```bash
cd frontend
npm install
```

For the backend:

```bash
cd ../backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

### 5. Start the Backend

```bash
npm start
```

### 6. Start the Frontend

Open another terminal:

```bash
cd frontend
npm start
```

The application will run locally.
